DARK CITY M-MENU IMAGE LIBRARY
================================
All new/replacement M-menu artwork lives here:
html/img/m-menu/

Requested modules:
family/
faction/
jobs/
business/
settings/
daily-reward/
achievement/
referral/
statistics/

Each subfolder contains ONLY images used by that module's visual image mapping.
To change an image: replace the JPG with your own image using the EXACT SAME filename.
Recommended size: 1000x600 or 1280x720.
Then: restart dc-core-ui

Example:
html/img/m-menu/family/members.jpg
Replace that file with your own members image, keep the name members.jpg.

Do not delete/rename files unless you also update ALL_TABS_IMAGE_MAP.json/app.js.
Original html/img assets outside m-menu were preserved because the existing resource may use them.
